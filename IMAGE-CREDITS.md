# Image credits

Every photograph on this site is royalty-free and cleared for commercial reuse.
Sources were found through [Openverse](https://openverse.org), filtered to **CC0**
and **Public Domain Mark** only, and hosted on Wikimedia Commons or Flickr.

Neither licence requires attribution. This file exists so the provenance of every
image is recorded and checkable — keep it with the project.

> **These are stock photographs, not Flow Forward Africa's own programmes.**
> They illustrate the kind of work described on each page. Replace them with FFA's

## Rebuilding

Images were centre-cropped and encoded with macOS `sips` at quality 68–72,
sized to the slot each one fills (2× for the smaller slots). Originals are not
kept in the repo; the source links above resolve to them.
